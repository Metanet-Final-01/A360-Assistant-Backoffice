# 업무 정의서

과제명: 폴더 내 파일 보관(아카이브) 처리

## Task 1 — 실행 준비 (로그 구성)
작업 순서:
1. 오늘 날짜 기준으로 감사 로그·오류 로그·스냅샷 폴더를 만든다
2. 로그 파일이 없으면 만든다
3. 보관 기간이 지난 이전 로그 폴더는 삭제한다

사용 프로그램 및 시스템: -

## Task 2 — 보관 폴더 준비
작업 순서:
1. 보관 폴더가 없으면 만든다
2. 보관 폴더 안에 오늘 날짜로 된 하위 폴더를 만든다

사용 프로그램 및 시스템: -

## Task 3 — 파일 보관 처리
작업 순서:
1. 입력 폴더의 파일을 한 개씩 처리한다
2. 파일을 오늘 날짜 하위 폴더로 복사한다
3. 복사가 끝난 원본 파일은 입력 폴더에서 삭제한다

사용 프로그램 및 시스템: -

## Task 4 — 처리 결과 기록 및 오류 처리
작업 순서:
1. 처리 과정을 감사 로그에 기록한다
2. 실행 중 오류가 나면 오류 내용을 오류 로그에 남긴다
3. 오류 발생 시점의 화면을 캡처해 스냅샷 폴더에 저장한다

사용 프로그램 및 시스템: -
