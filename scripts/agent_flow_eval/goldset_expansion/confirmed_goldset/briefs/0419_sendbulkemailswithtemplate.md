# 업무 정의서

과제명: 템플릿 기반 대량 이메일 발송

## Task 1 — 입력 파일 확인
작업 순서:
1. 입력 폴더에 수신자 목록 파일이 있는지 확인한다
2. 파일이 없으면 안내 후 작업을 중단한다

사용 프로그램 및 시스템: 입력 폴더

## Task 2 — 수신자 목록과 메일 양식 읽기
작업 순서:
1. 수신자 목록 시트를 연다
2. 수신자 정보 전체 행을 읽어온다
3. 메일 양식 시트를 연다
4. 메일 제목과 본문 양식을 읽어온다

사용 프로그램 및 시스템: Excel

## Task 3 — 수신자별 메일 발송
작업 순서:
1. 수신자 목록을 한 행씩 처리한다
2. 수신자의 이름·부서·받는사람·참조·숨은참조·첨부파일 정보를 꺼낸다
3. 메일 양식의 치환 표시(부서, 이름, 날짜)를 수신자 정보로 바꾼다
4. 완성된 제목과 본문으로 메일을 발송한다

사용 프로그램 및 시스템: Outlook

## Task 4 — 발송 결과 기록
작업 순서:
1. 발송에 성공하면 해당 수신자 행에 성공 표시를 남긴다
2. 발송하지 못했으면 실패 표시를 남긴다
3. 결과를 반영해 파일을 저장한다

사용 프로그램 및 시스템: Excel

## Task 5 — 처리 완료 파일 정리
작업 순서:
1. 결과가 기록된 파일을 출력 폴더로 옮긴다
2. 입력 폴더의 원본을 삭제한다
3. 실행 중 오류가 나면 오류 내용을 기록으로 남긴다

사용 프로그램 및 시스템: 입력 폴더, 출력 폴더
