# 업무 정의서

과제명: 공휴일 캘린더 기반 다음 영업일 계산

## Task 1 — 실행 준비 (로그·폴더 구성)
작업 순서:
1. 오늘 날짜 기준으로 로그용 하위 폴더(감사 로그/오류 로그/스냅샷)를 만든다
2. 감사 로그 파일과 오류 로그 파일이 없으면 만든다
3. 보관 기간이 지난 이전 로그 폴더는 삭제한다

사용 프로그램 및 시스템: -

## Task 2 — 공휴일 캘린더 확인
작업 순서:
1. 공휴일 목록이 담긴 엑셀 파일을 연다

사용 프로그램 및 시스템: Excel

## Task 3 — 다음 영업일 계산
작업 순서:
1. 오늘 날짜부터 하루씩 늘려가며 확인한다
2. 주말이면 다음 날로 넘어간다
3. 공휴일 목록에 있는 날짜면 다음 날로 넘어간다
4. 주말도 공휴일도 아닌 날짜를 찾을 때까지 반복한다

사용 프로그램 및 시스템: -

## Task 4 — 결과 안내 및 마무리
작업 순서:
1. 계산된 다음 영업일을 화면에 안내한다
2. 처리 과정을 감사 로그에 기록한다
3. 엑셀 파일을 닫는다

사용 프로그램 및 시스템: Excel

## Task 5 — 오류 처리
작업 순서:
1. 실행 중 오류가 나면 오류 내용을 오류 로그에 남긴다
2. 오류 발생 시점의 화면을 캡처해 스냅샷 폴더에 저장한다

사용 프로그램 및 시스템: -
