# 업무 정의서

과제명: 공휴일 제외 이전 영업일 계산

## Task 1 — 공휴일 목록 읽기
작업 순서:
1. 공휴일 목록이 담긴 엑셀 파일을 연다
2. 공휴일 날짜를 한 행씩 읽어 목록에 저장한다
3. 엑셀 파일을 닫는다

사용 프로그램 및 시스템: Excel

## Task 2 — 이전 영업일 계산
작업 순서:
1. 오늘 날짜부터 하루씩 거슬러 올라가며 확인한다
2. 주말이면 건너뛴다
3. 공휴일 목록에 있는 날짜면 건너뛴다
4. 주말도 공휴일도 아닌 날짜를 찾을 때까지 반복해 결과 목록에 담는다

사용 프로그램 및 시스템: -
