# 업무 정의서

과제명: 시스템 임시 파일·폴더 정리

## Task 1 — 실행 준비 (로그 구성)
작업 순서:
1. 오늘 날짜 기준으로 감사 로그·오류 로그·스냅샷 폴더를 만든다
2. 로그 파일이 없으면 만든다
3. 보관 기간이 지난 이전 로그 폴더는 삭제한다

사용 프로그램 및 시스템: -

## Task 2 — 정리 대상 폴더 확인
작업 순서:
1. 임시 파일 폴더, 최근 문서 폴더, Prefetch 폴더, Windows 임시 폴더 경로를 확인한다

사용 프로그램 및 시스템: -

## Task 3 — 폴더별 파일 정리
작업 순서:
1. 정리 대상 폴더를 하나씩 처리한다
2. 폴더 안의 파일을 한 개씩 삭제한다
3. 삭제에 실패한 파일은 오류로 기록하고 다음 파일로 넘어간다

사용 프로그램 및 시스템: -

## Task 4 — 폴더별 하위 폴더 정리
작업 순서:
1. 정리 대상 폴더를 하나씩 처리한다
2. 폴더 안의 하위 폴더를 한 개씩 삭제한다
3. 삭제에 실패한 폴더는 오류로 기록하고 다음 폴더로 넘어간다

사용 프로그램 및 시스템: -

## Task 5 — 처리 결과 기록 및 오류 처리
작업 순서:
1. 처리 과정을 감사 로그에 기록한다
2. 실행 중 오류가 나면 오류 내용을 오류 로그에 남긴다
3. 오류 발생 시점의 화면을 캡처해 스냅샷 폴더에 저장한다

사용 프로그램 및 시스템: -
