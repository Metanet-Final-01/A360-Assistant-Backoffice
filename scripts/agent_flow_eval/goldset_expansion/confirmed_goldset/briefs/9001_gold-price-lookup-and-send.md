# 업무 정의서

과제명: 금 시세 조회 후 결과 발송

## Task 1 — 실행 준비
작업 순서:
1. 오늘 날짜를 조회 기준일로 만든다
2. 결과 파일을 저장할 경로를 만든다

사용 프로그램 및 시스템: -

## Task 2 — 금 시세 조회
작업 순서:
1. 브라우저를 시작하고 금 시세 조회 페이지로 이동한다
2. 조회에 필요한 항목을 선택한다
3. 화면에 표시된 시세 표를 가져온다

사용 프로그램 및 시스템: Chrome, 금 시세 조회 사이트

## Task 3 — 조회 결과 정리
작업 순서:
1. 가져온 표에서 불필요한 행을 지운다
2. 표 앞쪽에 제목 행을 추가한다

사용 프로그램 및 시스템: -

## Task 4 — 엑셀 파일로 저장
작업 순서:
1. 결과를 담을 엑셀 파일을 새로 만든다
2. 정리한 표를 시트에 기록한다
3. 표가 보기 좋도록 서식을 맞춘다
4. 파일을 저장하고 닫는다

사용 프로그램 및 시스템: Excel

## Task 5 — 결과 메일 발송
작업 순서:
1. 메일 계정에 연결한다
2. 저장한 엑셀 파일을 첨부해 결과 메일을 보낸다
3. 메일 계정 연결을 해제한다

사용 프로그램 및 시스템: Gmail
