# 업무 정의서

과제명: 신규 사용자 등록 정보 고유 ID 생성 및 엑셀 기록

## Task 1 — 폴더 및 로그 파일 준비
작업 순서:
1. 작업 폴더, 로그 폴더, 결과 폴더가 없으면 각각 만든다
2. 실행 로그 파일이 없으면 만든다

사용 프로그램 및 시스템: -

## Task 2 — 고유 사용자 ID 생성
작업 순서:
1. 임의의 참조 번호를 만든다
2. 이름 문자열을 뒤집어 일부를 잘라낸다
3. 잘라낸 문자열과 참조 번호를 합쳐 고유 사용자 ID를 만든다

사용 프로그램 및 시스템: -

## Task 3 — 첨부 파일 다운로드
작업 순서:
1. 필요한 경우 관련 파일을 내려받는다

사용 프로그램 및 시스템: -

## Task 4 — 사용자 정보 엑셀 기록
작업 순서:
1. 결과 엑셀 파일을 연다
2. 다음 빈 행으로 이동해 이름·성을 기록한다
3. 다음 빈 셀로 이동해 이메일 주소를 기록한다
4. 다음 빈 셀로 이동해 주소·도시·주·우편번호를 차례로 기록한다
5. 다음 빈 셀로 이동해 휴대폰 번호와 생성된 사용자 ID를 기록한다

사용 프로그램 및 시스템: Excel

## Task 5 — 완료 처리 및 오류 기록
작업 순서:
1. 처리가 끝나면 완료를 알린다
2. 실행 중 오류가 나면 오류 내용을 알린다
3. 성공·실패 여부를 로그 파일에 남긴다
4. 엑셀 파일을 닫는다

사용 프로그램 및 시스템: Excel
