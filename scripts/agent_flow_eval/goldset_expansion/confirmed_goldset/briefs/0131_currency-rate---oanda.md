# 업무 정의서

과제명: Oanda 환율 조회 후 엑셀 기록

## Task 1 — 조회 대상 목록 열기
작업 순서:
1. 조회할 통화쌍 목록이 담긴 엑셀 파일을 연다
2. 결과를 기록할 시작 셀로 이동한다

사용 프로그램 및 시스템: Excel

## Task 2 — 환율 조회 사이트 접속
작업 순서:
1. 브라우저를 시작한다
2. Oanda 환율 변환 페이지로 이동한다
3. 페이지가 다 열릴 때까지 기다린다

사용 프로그램 및 시스템: Chrome, Oanda 환율 사이트

## Task 3 — 통화쌍별 환율 조회 및 기록
작업 순서:
1. 통화쌍 목록을 한 행씩 처리한다
2. 페이지가 준비될 때까지 기다린다
3. 기준 통화 입력란에 기준 통화를 입력한다
4. 대상 통화 입력란에 대상 통화를 입력한다
5. 환산할 금액을 입력한다
6. 환산 결과가 표시될 때까지 기다린다
7. 표시된 환율 값을 가져온다
8. 가져온 값을 엑셀의 현재 셀에 기록한다
9. 다음 통화쌍을 기록할 위치로 셀을 옮긴다

사용 프로그램 및 시스템: Chrome, Excel, Oanda 환율 사이트

## Task 4 — 마무리
작업 순서:
1. 브라우저를 닫는다
2. 엑셀 파일을 닫는다
3. 실행 중 오류가 나면 오류 내용을 기록으로 남긴다

사용 프로그램 및 시스템: Chrome, Excel
