# 업무 정의서

과제명: 설정 기반 파일 백업

## Task 1 — 설정값 읽기
작업 순서:
1. 설정이 담긴 엑셀 파일을 연다
2. 원본 폴더, 대상 폴더, 하위 폴더명, 파일명 조건 등 설정값을 각 셀에서 읽어온다
3. 엑셀 파일을 닫는다

사용 프로그램 및 시스템: Excel

## Task 2 — 백업 폴더 준비
작업 순서:
1. 오늘 날짜가 포함된 백업 하위 폴더 경로를 만든다
2. 폴더가 없으면 만든다

사용 프로그램 및 시스템: -

## Task 3 — 파일 백업 처리
작업 순서:
1. 설정된 파일명 조건(정확한 이름 일치/앞부분 일치/뒷부분 일치)에 따라 대상 파일을 찾는다
2. 처리 시작을 화면에 안내한다
3. 대상 파일을 백업 폴더로 복사한다
4. 복사가 끝난 원본 파일은 원본 폴더에서 삭제한다

사용 프로그램 및 시스템: -

## Task 4 — 오류 처리
작업 순서:
1. 실행 중 오류가 나면 오류 내용과 시각을 로그 파일에 남긴다
2. 오류 발생 시점의 화면을 캡처해 저장한다

사용 프로그램 및 시스템: -
