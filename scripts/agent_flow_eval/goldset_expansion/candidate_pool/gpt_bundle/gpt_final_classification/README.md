## 매핑 시 유의사항 (다음에 또 이런 작업할 때 참고)

xlsx의 4자리 ID는 **봇(bot) 폴더 단위 번호**라 유일하지 않다. 한 봇 폴더 밑에 서브
워크플로우 파일이 여러 개 있으면 같은 ID를 여러 파일이 공유한다 (예: `0036`은
GenAI-GetRecommendation / Setup Log Folders And Locations / UpdateKnowledgeBase 세 개
파일이 같은 ID). 그래서 단순히 "ID로 찾기"만 하면 엉뚱한 파일이 걸릴 수 있다 — 실제로
초안 스크립트에서 이 버그로 0017/0033/0048이 잘못 매칭된 적이 있음. 반드시 ID로 1차
후보를 좁힌 뒤, 후보가 여럿이면 candidate 이름(정규화: 소문자+영숫자만) 매칭으로
파일명 꼬리(마지막 `__` 뒤)와 대조해야 한다.

`0203 API User Management Bot`(Challenge)은 같은 봇 폴더에 `APIMaster.goldset.json`
(steps 15개, 인증→조회→분기 전체 흐름)과 `DeleteUserID.goldset.json`(하위 서브태스크)
두 파일이 있어 이름 매칭으로도 구분이 안 돼 수동으로 `APIMaster`를 선택함 (xlsx의 판정
근거 "인증 → 역할·사용자 조회 → 사용자 존재 여부 판단 → 생성 또는 삭제 분기 구조"가
전체 오케스트레이션 파일을 가리키는 것으로 판단).
