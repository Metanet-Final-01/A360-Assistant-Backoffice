# hybrid+rerank 검색 파이프라인 (별도 슬라이드)

*chunk_size/overlap 확정과는 별개 트랙 — 검색 방식(vector-only vs BM25+vector 융합+재정렬) 관련.*

---

## 실측 완료 — vector-only vs hybrid+rerank

로컬 EXAONE-4.0, tok1024 기준, 129건 전체 (2026-07-26)

| 지표 | vector-only | hybrid+rerank |
|---|---|---|
| Hit@1 | 0.341 | 0.690 |
| MRR | 0.452 | 0.799 |
| Context Precision | 0.736 | 0.946 |
| Context Recall | 0.864 | 0.977 |
| Evidence Coverage | 0.729 | 0.915 |

→ hybrid+rerank 도입으로 검색 지표 전반이 큰 폭으로 개선 (Hit@1 2배, MRR +35%p)

---

## anchor(RRF) vs 정규화 융합 2종 (실측 완료, 2026-07-26)

| 설정 | Hit@5 | MRR | Evidence Coverage | Faithfulness |
|---|---|---|---|---|
| anchor (RRF, k=60) | 0.9225 | 0.7991 | 0.9147 | 0.9268 |
| 정규화 융합(ranking형) | 0.9535 | 0.8114 | 0.9457 | 0.9087 |
| 정규화 융합(coverage형) | 0.9612 | 0.8172 | 0.9457 | 0.9190 |

→ 검색 지표는 방향성 있게 개선되나, 129건 표본 기준 통계적으로 유의한 차이는 확인 안 됨(참고용 수치)
