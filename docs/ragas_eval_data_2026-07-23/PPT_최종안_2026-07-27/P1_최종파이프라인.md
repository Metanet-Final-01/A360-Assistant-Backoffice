# P1. 최종 검색 파이프라인

## 처리 순서

```text
질문
→ BM25(키워드) + Vector(의미) 각각 검색
→ 정규화 융합(min-max + arithmetic_mean)으로 결합(Hybrid)
→ Candidate Pool
→ Reranker(Voyage rerank-2.5-lite)
→ Final Top-K
→ 답변 생성
```

## 확정값

| 항목 | 값 | 상태 |
|---|---|---|
| Chunk size | **1200자** (char 기준) | ✅ 확정 |
| Overlap | **10%** (120자) | ✅ 확정 |
| 검색 방식 | BM25 + Vector | ✅ 확정 (Vector-only 대비 압도적 개선, P3 참고) |
| 결합 방식 | 정규화 융합(min-max+arithmetic_mean, w_bm25=0.5/w_vector=0.5) | ✅ 확정 — 16개 fusion 설정 실제 Context Precision/Recall 재검증 완료, RRF 대비 HM +0.8~1.1%p(P4 참고) |
| Candidate pool | 100~150(branch당) | ✅ 확정 — 100 근방부터 포화 확인 |
| Reranker | Voyage rerank-2.5-lite | ✅ 확정 |
| Rerank 후보 수 | 50 | ✅ 확정 — 100까지 늘려도 결과 동일(비용만 증가), 기존 20보다 개선 확인 |
| Final top-k | 5 | ✅ 확정 |

## 이 페이지에서 전달할 내용

> **문서 분할부터 최종 검색 결과까지 전체 설정을 확정했다.** 결합 방식(정규화 융합)·candidate pool(100~150)·rerank 후보 수(50)까지 실제 Context Precision/Recall로 재검증을 마쳤다(2026-07-27).
