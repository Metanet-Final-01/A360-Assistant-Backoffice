# 골드셋(평가용 질문-정답 세트) 생성 방법

*129건(전체 160건 중 승인+활성) 골드셋이 어떻게 만들어졌는지. ops-server(Streamlit 관리 UI) 기준.*

---

## 1. 문서 무작위 추출

- 위치: `ops-server/backend/app/eval/ragas_eval/source_documents.py`의 `random_sample()`, API로는 `GET /eval/ragas/source-documents/random`
- UI: `ops-server/backend/app/eval/ragas_eval` 관리 화면의 "작성" 탭(Streamlit)

**실제 동작**:
1. 화면에서 "문서 유형" 드롭다운으로 **하나** 선택 — `(전체) / doc_page / action_schema / package_overview` 중 하나
2. "이미 작성된 문서 제외" 체크박스(기본 켜짐) — 기존 골드셋의 `reference_doc_ids`·`reference_contexts[].source_document_id`에 이미 등장한 문서는 자동 제외
3. "무작위 선택" 버튼 클릭 → 그 유형에서 무작위로 최대 5개 문서 추출(`ORDER BY random() LIMIT 5`)
4. **유형별로 이 과정을 반복** — "한 번에 유형별 5개씩 전부"가 아니라, 유형 하나 골라 5개 뽑고, 다음 유형으로 바꿔서 또 5개 뽑는 식(수동 반복)

---

## 2. 질문-정답 작성 (AI 초안 + 사람 검토)

이 화면 자체의 설계 의도가 문서에 명시되어 있음: *"AI 자동 초안 생성은 아직 없음(직접 연동 안 됨) — 사람이 ChatGPT 웹 등으로 초안을 만들어와서 이 화면에서 원문과 대조하며 입력한다."*

실제 흐름:
1. 추출된 문서 하나를 선택하면, 화면이 그 문서 내용을 넣은 **"ChatGPT용 프롬프트"**를 만들어줌(복사용 템플릿)
2. 이 프롬프트를 사람이 직접 ChatGPT(웹)에 붙여넣어 질문+정답 초안을 받음
3. ChatGPT의 JSON 응답을 화면의 **"응답 붙여넣어 자동 채우기"** 박스에 붙여넣으면 질문/정답/근거스니펫 필드가 자동으로 채워짐
4. **사람이 원문과 대조하며 직접 검토·수정**
5. 저장 — 저장 시점에 이미 사람이 검토했다는 전제로 기본값 `status=approved`, 문제 있으면 반려 사유 선택 후 `rejected`로 저장 가능

---

## 3. 골드셋 케이스 구조 (JSON)

파일: `ops-server/backend/app/eval/ragas_eval/cases/rag_goldset_v1.json`

```json
{
  "case_id": "rag_0cabf5ee_4fcea9",
  "question": "사용자 생성 작업에서 '다음 로그인 시 비밀번호 변경 필요 없음' 옵션을 선택하면 추가로 선택할 수 있는 옵션은 무엇입니까?",
  "ground_truth": "'사용자가 비밀번호를 변경할 수 없음'과 '비밀번호가 만료되지 않음' 옵션을 추가로 선택할 수 있습니다.",
  "reference_doc_ids": ["0cabf5ee73bb387b"],
  "reference_contexts": [{"source_document_id": "0cabf5ee73bb387b", "snippet": "..."}],
  "status": "approved",
  "review_note": null,
  "question_type": "조건 조회",
  "dataset_membership": "active"
}
```

| 필드 | 의미 |
|---|---|
| `case_id` | 케이스 고유 ID |
| `question` | 질문 |
| `ground_truth` | 사람이 검증한 정답(요약) |
| `reference_doc_ids` | 정답 근거 문서 ID(참고용, 채점에는 직접 안 씀) |
| `reference_contexts` | 실제 근거 스니펫 — `source_document_id`+`snippet` — EvidenceCoverage/gold 경계 체크 등에서 사용 |
| `status` | `draft`(초안) / `approved`(승인) / `rejected`(반려) |
| `question_type` | 4종: 단순 조회 / 조건 조회 / 절차 설명 / 비교·판단 |
| `dataset_membership` | `active`(현재 평가셋에 포함) / `candidate`(후보) / `excluded`(제외) |

**주의**: `문서유형`(doc_page/action_schema/package_overview) 자체는 케이스에 저장되지 않음 — 추출 당시에만 쓰이고, 이후 문서유형별 분석이 필요하면 `source_documents` 테이블과 `reference_doc_ids`/`source_document_id`를 조인해서 알아냄.

**실제 평가에 쓰인 129건** = 전체 160건 중 `status=approved` AND `dataset_membership=active` 필터링 결과.
